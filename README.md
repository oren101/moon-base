# OREN · Moon Base

Public isometric 3D cutaway of Oren's Hebrew Moon Base — bots, floors, eclipse mode, and a hidden TMA-1 chamber.

Built with Three.js (CDN), soft shadows, bloom, ACES tone mapping. Privacy-scrubbed data in `data.json`.

**Repo:** https://github.com/oren101/moon-base  
**Live (after Pages is on):** https://oren101.github.io/moon-base/

## Enable GitHub Pages (one-time)

Actions cannot create the Pages site for this repo (`Resource not accessible by integration`). In the GitHub UI:

1. Open https://github.com/oren101/moon-base/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Re-run the **Deploy GitHub Pages** workflow (Actions tab → Run workflow), or push any commit to `main`

After that the site serves from `main` via `.github/workflows/pages.yml`.
